# 实验一代码附录

## 主要源码文件

- `experiment1/main.py`：实验主入口，串联新闻清洗、情感标注、周度情绪、羊群指标、LGBM建模、报告输出。
- `experiment1/data.py`：读取新闻与沪深300行情、交易日过滤、5交易日周度聚合、CSV/SQLite输出。
- `experiment1/sentiment.py`：FinBERT情感标注与词典兜底逻辑。
- `experiment1/analysis.py`：羊群指标构造、特征工程、LightGBM预测、SHAP和双向传导分析。
- `experiment1/plots.py`：周度情绪、羊群指标、模型结果和特征重要性图表。
- `experiment1/config.py`：路径、日期范围、学生信息和实验参数。

## 运行命令

```powershell
pip install -r requirements.txt
python -m experiment1.main
```
