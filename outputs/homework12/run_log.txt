第八步：业务结论与特征重要性分析
======================================================================

========== 业务结论 ==========

【研究假设验证】
假设1: 报案延迟过长与欺诈风险正相关
  → 通过policy_tenure_days（保单持有时长）和incident_hour_of_the_day（事故时段）
    等衍生特征验证，异常的时间模式是欺诈行为的重要信号。

假设2: 索赔金额异常与欺诈风险正相关
  → 通过claim_to_premium_ratio（索赔/保费比）和total_claim_amount
    验证，高额索赔且与保费不匹配的案件欺诈风险显著增加。

假设3: 历史行为特征与欺诈风险相关
  → 通过capital-gains/capital-loss、customer_months等特征验证，
    投保人的财务行为和保险历史对欺诈预测有参考价值。

【高欺诈风险行为画像（基于模型分析）】
  1. 索赔金额/保费比率异常偏高 → 可能虚报损失金额
  2. 深夜（0-5点）发生事故 → 可能蓄意制造事故现场
  3. 无人受伤却高额索赔 → 索赔项目与实际不符
  4. 保单生效后短时间内出险 → 可能为预谋欺诈
  5. 无目击证人或无警方报告 → 缺乏第三方验证
  6. 老旧车辆高额索赔 → 车辆价值与索赔金额不匹配

【模型推荐】
  综合验证集AUC，推荐使用决策树模型（AUC=0.863, F1=0.6154, 召回率=0.5556），
  其在反欺诈识别性能上表现最优，适合作为车险索赔欺诈的初步筛查模型。
  特征重要性分析采用随机森林的解释性输出，辅助业务理解高风险因素。

【风控建议】
  1. 建立实时欺诈评分机制，对高风险案件进行人工复核
  2. 重点关注深夜事故、高额索赔、无证人案件
  3. 将模型输出作为辅助决策工具，结合理赔员经验综合判断
  4. 定期更新模型，适应新出现的欺诈模式
