# 作业11：银行信用评分模型 - 实验报告

## 一、实验概述

### 1.1 实验名称
消费金融用户信用评分与违约风险预测。

### 1.2 实验目标
1. 基于用户多维度数据，建立标准化个人信用风险评分体系。
2. 构建高可解释性的逻辑回归信用评分卡。
3. 量化分析影响用户信用等级与违约概率的核心特征。
4. 输出可落地的信用风险评估规则与信用提升建议。

### 1.3 数据来源
阿里天池公开数据集：违约贷款数据集（数据集ID：140861）。

## 二、数据概况

### 2.1 数据规模
- 训练集：800,000 条记录，47 个字段。
- 测试集：200,000 条记录，46 个字段。

### 2.2 目标变量分布

|------|------|------|
| 正常还款（isDefault=0） | 640,390 | 80.05% |
| 违约（isDefault=1） | 159,610 | 19.95% |

### 2.3 缺失值概况
主要缺失特征如下：

| 特征 | 缺失数量 | 缺失比例 |
|------|----------|----------|

## 三、实验方法

### 3.1 数据预处理
1. 将 `employmentLength` 转换为数值型工作年限。
2. 从 `issueDate` 提取年份、月份和星期特征。
3. 从 `earliesCreditLine` 提取最早信用记录年份。
4. 分类特征仅使用建模训练集拟合编码映射，验证集和测试集未见类别统一映射为未知类别。
5. 缺失值填充仅使用建模训练集的中位数，避免验证集和测试集信息泄露。

### 3.2 特征筛选
在建模训练集上进行相关性分析和 IV 筛选：

| 特征 | IV值 | 预测能力 |
|------|------|----------|
| subGrade | 0.4868 | 强 |
| ficoRangeLow | 0.1258 | 中等 |
| dti | 0.0715 | 弱 |
| n14 | 0.0428 | 弱 |
| loanAmnt | 0.0341 | 弱 |
| issueYear | 0.0337 | 弱 |
| n2 | 0.0309 | 弱 |
| annualIncome | 0.0292 | 弱 |
| verificationStatus | 0.0263 | 弱 |
| revolUtil | 0.0252 | 弱 |
| title | 0.0211 | 弱 |

最终选择 IV 值不低于 0.02 的 11 个特征进入模型。

### 3.3 WOE评分卡建模
模型采用“特征分箱 + WOE 转换 + 标准化 + 逻辑回归”的流程：

- 先在建模训练集上拟合 WOE 分箱规则。
- 交叉验证使用 Pipeline，保证每一折内部独立拟合 WOE 转换器和标准化器。
- 信用分公式为：`Score = Offset + Factor * ln((1-p)/p)`。
- 其中 `p` 为违约概率，好坏比越高，信用分越高。

评分卡参数：

| 参数 | 值 |
|------|------|
| 基础分数 BASE_SCORE | 600 |
| PDO | 50 |
| BASE_ODDS | 1 |
| Factor | 72.13 |
| Offset | 600.00 |
| 评分范围 | 300-850 |

## 六、信用提升建议

1. 维护良好的还款记录，避免逾期和连续逾期。
2. 控制负债收入比（DTI），避免超出偿债能力的借贷。
3. 提高或保持稳定收入水平，增强还款能力。
4. 改善信用等级和 FICO 评分相关指标。
5. 控制循环额度使用率，避免长期高额占用授信额度。
6. 减少短期内频繁申请新信贷，保持稳定信用历史。
