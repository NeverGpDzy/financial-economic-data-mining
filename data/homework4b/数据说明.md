## 注意事项

1. 日期格式为YYYYMMDD整数，使用时需转换：`pd.to_datetime(df['trade_date'], format='%Y%m%d')`
2. 股票代码格式为Tushare格式（如600519.SH），与Baostock格式（sh.600519）不同
3. 数据覆盖范围：2019-01-02 至 2025-12-31
4. 无个股级别资金流向数据（moneyflow_stock），MoneyFlow因子使用5日滚动签名成交额净流入 / 流通市值代理；签名成交额 = amount/10 × sign(ret)
5. 因子去极值采用交易日截面3σ缩尾，避免用样本外年份估计全样本阈值

## 因子计算说明

| 因子 | 计算公式 | 数据来源 |
|------|----------|----------|
| Reversal | -pct_chg（取负号） | daily |
| Liquidity | \|pct_chg\| / amount（Amihud指标） | daily |
| MoneyFlow | 5日滚动签名成交额净流入 / circ_mv；签名成交额 = amount/10 × sign(ret) | daily + daily_basic |
| Value | 1 / pe_ttm | daily_basic |
