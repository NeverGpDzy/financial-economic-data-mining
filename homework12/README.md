# 作业12：保险反欺诈检测

## 一、实验名称

车险索赔反欺诈模型构建与特征分析

## 二、数据来源

阿里天池公开金融风控数据集（车险索赔脱敏数据），具体对应天池【教学赛】金融数据分析赛题2：保险反欺诈预测数据集，核心信息如下：

- 官方数据集ID：136254（主数据集），镜像/复刻版ID：189882、171696（数据分析系列赛事第2场配套数据集）
- 赛题入口：天池学习赛【保险反欺诈预测】（入口ID：531994）
- 数据规模：训练集700条样本（含38个特征），测试集300条样本（含37个特征），均为车险索赔脱敏数据，适配教学与科研场景
- 数据文件：包含train.csv（训练集，含标签）、test.csv（测试集，无标签）、submission.csv（提交样例），可直接下载使用，无需复杂权限
- 访问链接：https://tianchi.aliyun.com/dataset/136254

## 三、数据字段（常用）

- **投保人信息**：年龄（对应数据集age字段）、性别（对应insured_sex字段）、驾龄（数据集中隐含可衍生）、婚姻状况（对应insured_relationship字段）
- **车辆信息**：车型（对应auto_make/auto_model字段）、车龄（对应auto_year字段，可通过当前年份与车辆购买年份衍生）、购买价格（数据集中隐含相关特征，可辅助分析）
- **事故信息**：事故时间（对应incident_date字段）、地点（对应incident_state/incident_city字段）、报案时间（数据集中隐含，可衍生）、是否有现场（对应police_report_available字段）、责任认定（对应collision_type字段）
- **索赔信息**：索赔金额（对应total_claim_amount字段）、历史出险次数（可通过样本衍生构建）、历史赔付金额（数据集中隐含相关特征）
- **标签**：fraud（1=欺诈，0=正常索赔），与数据集标签完全一致

## 四、实验目标

1. 完成数据探索（EDA），识别欺诈案件的核心特征与分布规律
2. 构建高效的二分类模型，实现车险索赔欺诈案件的精准识别
3. 解释哪些行为（如报案延迟、金额异常等）最容易被判定为高欺诈风险，输出可落地的业务结论

## 五、实验步骤

1. **数据读取与基本信息统计**：读取天池数据集（train.csv、test.csv），查看数据结构、特征类型、样本分布，统计基本描述性信息
2. **缺失值、异常值处理**：检测各字段缺失情况，采用合理方式填充（如均值、中位数、众数）；识别异常值（如索赔金额异常、时间异常），进行剔除或修正
3. **欺诈 vs 正常样本对比分析**：对比两类样本在各特征上的分布差异，挖掘欺诈案件的典型特征
4. **特征工程**：衍生关键特征（报案延迟、索赔金额异常、历史出险频率等），对分类特征进行编码、数值特征进行标准化，剔除冗余特征
5. **模型构建**：选用逻辑回归、决策树或轻量集成模型（如随机森林），完成模型训练与参数调优
6. **模型评估**：计算并输出精确率、召回率、F1值、AUC等二分类评估指标，验证模型效果（AUC≥0.7为可用标准）
7. **输出特征重要性与业务结论**：分析模型特征重要性，明确高欺诈风险行为，形成可解释的业务结论

## 六、科学顾问（豆包）负责

- 欺诈行为的业务逻辑解释：解读欺诈案件的特征规律，说明高风险行为的合理性
- 结果合理性分析：验证模型输出结果与业务逻辑的一致性，分析模型误差原因
