**金融数据作业6B：基于FCFF的价值投资**

------ 巴菲特·芒格的三好价值投资（传统规则选股+机器学习多因子双实证）

**一、作业概述**

本作业在原有巴菲特"三好价值投资"定性转量化基础上，**按**多因子全链路检验：因子预处理→IC/IR有效性检验→VIF共线性筛查→单因子截面回归→LGBM非线性赋权打分，构建**两套价值选股方案对照回测**：

方案A：原版固定财务阈值硬性筛选（传统价值规则选股）

方案B：基于财务因子机器学习综合打分选股（量化多因子价值模型）

实验新增目标：

1.理念理解：深入理解巴菲特"优质股权长期持有"与芒格"护城河优先"的核心投资哲学。

2.量化转化：将"好赛道、好商业模式、经济护城河、长期现金流"定性理念转为10项标准化财务因子。

3.量化质检：参照机构标准完成**IC/IR因子有效性、VIF共线性、单因子OLS显著性检验**，筛选有效价值因子。

4.模型建模：使用LGBM机器学习对有效财务因子非线性赋权，生成价值综合得分。

5.实操能力：熟练运用CodeBuddy
AI辅助完成数据获取、因子计算、双策略选股、组合回测与可视化分析。

6.实证检验：两套价值组合分别回测，对比优劣，验证价值投资超额收益来源。

**二、核心思想与量化指标→标准化价值因子清单）**

**2.1 好商业模式因子（5个）**

F1：年净利润复合增速 F2：销售毛利率 F3：销售净利率
F4：固资/总资产（轻资产因子，反向因子，数值越低价值越高）
F5：资产负债率（反向因子）

**2.2 经济护城河因子（2个）**

F6：年平均ROE

F7：三费费率/营收（反向因子）

**2.3 长期现金流因子（4个，修订F8）**

F8：经营现金流净额/净利润（利润含金量）

F9：分红率

F10：股息率

因子方向标注：正向因子越大越好；反向因子越小越好，建模前统一正向化处理。

标签Y：FCFF年度增速= 每年（经营净现金-固定资产投入）增速

**三、实验数据与范围**

选股池：上证50指数成分股；

**数据拓展：财务数据起始时间前置至2005.01.01，行情2006.01.01-2025.12.31** 训练集：2006--2017（因子检验+LGBM训练），样本外回测：2018--2025 

**标签变量Y：个股未来1年FCFF；**

**IC计算采用季度滚动：每年度末统计因子，对应标签Y，生成年度截面数据**

数据：年度财报财务数据、单季度财报、复权收盘价、分红、沪深300基准指数。

**四、实验分步任务**

整体流程：数据加载&因子计算→因子质检(IC+IR+VIF)→单因子有效性检验→LGBM模型赋权打分→双策略选股+双组合回测

**任务1：数据加载+全因子计算&预处理**

AI指令模板：

读取上证50成分股2006-2025季度+年度财务数据与日度行情，完成：

1.  计算10个价值财务因子F1-F10；不满5/10年历史数据的个股做剔除处理；

2.  计算标签Y：每年度末截面，未来1年FCFF；

3.  反向因子正向化处理、3σ缩尾去极值、缺失值填充；

4.  按季度整理截面数据集，拆分训练区间2006-2017、测试区间2018-2025。

**任务2：因子标准化+IC/IR+VIF共线性质检**

**检验规则：年度截面Spearman
IC；IC均值＞0.02为有效因子，IR=IC均值/IC标准差，\|IR\|＞0.1稳定性达标；VIF＞10剔除高共线因子** 

AI指令模板：

基于预处理后的年度因子数据集，代码实现：

1.  10个因子Z标准化；

2.  IC检验值对应标签Y

3.  逐年度截面计算Spearman IC、IC均值、IC标准差、IR；

4.  全因子VIF共线性检验，剔除VIF\>10因子；

5.  按照IC\>0.02筛选初步有效因子，输出检验汇总表。

**任务3：单因子年度截面OLS回归检验**

1.  回归公式：
    $Yi,t = \alpha + \beta \times Factori,t + \varepsilon$，Y=标签Y；

2.  判定：单因子逐年度截面回归，全期平均p＜0.05，因子线性有效；p≥0.05进入待定池，仍可参与LGBM非线性建模。

3.  AI指令模板：对筛选后有效因子逐年度做单因子OLS截面回归，统计全周期β均值、p值均值，输出线性有效因子清单。

**任务4：LGBM机器学习非线性赋权**

1.  训练集：2006-2017年度数据；特征=全部过质检因子，标签=标签Y；

2.  **模型优化：限制LGBM树深≤3，控制单棵树样本量，规避小样本过拟合**；5折时间序列交叉验证，输出各因子特征重要度；

3.  模型预测得分=个股综合价值分数（分数越高，未来中长期收益预期越高）。

**任务5：**

**回测1：FCFF回测**

模型，对当年所有个股输出模型价值得分，按年度截面，将个股得分从高到低均分
3 组（A/B/C）

A 档：模型最优价值组（理论未来 FCFF 增速最高）

C 档：模型最差价值组（理论未来 FCFF 增速最低）

2\. 统计每组真实未来 3 年 FCFF 年化增速均值，检验分层单调性：A＞B＞C

3\. 模型评价指标（全部改成适配 FCFF 基本面）

（1）分层回测核心指标：三组 FCFF 增速单调性

（2）A-C组 FCFF 增速差值（分层超额能力）
