# 作业11：银行信用评分模型 - 实验报告

## 一、实验概述

### 1.1 实验名称
消费金融用户信用评分与违约风险预测

### 1.2 实验目标
1. 基于用户多维度数据，建立标准化个人信用风险评分体系
2. 构建高可解释性的分类模型/标准信用评分卡
3. 量化分析影响用户信用等级与违约概率的核心特征
4. 输出可落地的信用风险评估规则与优化建议

### 1.3 数据来源
阿里天池公开数据集：违约贷款数据集（数据集ID：140861）

## 二、数据概况

### 2.1 数据规模
- **训练集**: 800,000 条记录，47 个特征
- **测试集**: 200,000 条记录，46 个特征

### 2.2 目标变量分布
| 类别 | 数量 | 比例 |
|------|------|------|
| 正常还款 (isDefault=0) | 640,390 | 80.05% |
| 违约 (isDefault=1) | 159,610 | 19.95% |

### 2.3 数据字段说明
- **个人信息**: 年龄、年收入、工作年限、家庭住房状况
- **负债信息**: 信贷额度、负债比（DTI）、贷款数量、贷款期限
- **征信行为**: 历史逾期次数、征信查询次数、历史还款表现、信用等级
- **目标标签**: default（1=违约，0=正常还款）

### 3.2 特征预处理

## 四、用户信用提升建议

### 4.1 核心影响因素分析

#### 正向影响因素（提高信用分数）
1. **annualIncome** (年收入): 贡献 +15.39 分
2. **ficoRangeLow** (FICO评分): 贡献 +10.71 分
3. **revolUtil** (循环利用率): 贡献 +1.97 分

#### 负向影响因素（降低信用分数）
1. **subGrade** (信用子等级): 贡献 -41.93 分
2. **issueYear** (贷款年份): 贡献 -9.94 分
3. **loanAmnt** (贷款金额): 贡献 -9.24 分
4. **dti** (负债收入比): 贡献 -6.76 分

### 4.2 信用提升建议

#### 核心建议
1. **维护良好的还款记录**
   - 按时还款是提升信用分数的最关键因素
   - 避免逾期，特别是连续逾期

2. **控制负债水平**
   - 保持较低的负债收入比(DTI)
   - 合理使用信贷额度，避免过度借贷

3. **建立稳定的信用历史**
   - 保持较长的信用历史
   - 避免频繁申请新信贷

4. **多元化信用组合**
   - 适度持有不同类型的信贷产品
   - 展示良好的多元信用管理能力

5. **保持稳定的财务状况**
   - 维持稳定的工作和收入来源
   - 合理规划个人财务

#### 具体行动建议
- 定期查看个人信用报告，及时发现并纠正错误
- 设置自动还款，避免因遗忘导致逾期
- 在申请大额贷款前，提前6个月优化信用状况
- 避免在短时间内多次申请信贷
- 保持信用卡使用率在30%以下

## 七、实验结论

### 7.1 模型性能
- AUC达到0.7005，超过0.7的可用标准
- KS值达到0.2935，接近30%的可用标准
- 模型具有较好的区分能力，可用于信用风险评估

### 7.2 核心发现
1. **信用子等级(subGrade)**是最重要的预测特征，IV值高达0.484
2. **FICO评分(ficoRangeLow)**和**负债比(dti)**是第二、三位重要特征
3. **年收入(annualIncome)**对信用评分有显著正向影响

### 7.3 应用价值
- 建立了标准化的信用评分体系（300-850分）
- 识别了影响违约概率的核心特征
- 提供了可操作的信用提升建议
- 模型可解释性强，适合金融风控场景
