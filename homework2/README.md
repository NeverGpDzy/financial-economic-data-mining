## 核心设置

- 模型拟合期：`2020-01-01` 至 `2022-12-31`
- 策略回测期：`2023-01-01` 至 `2024-12-31`
- 股票池：贵州茅台、中国石油、五粮液、泸州老窖、招商银行、美的集团
- 市场基准：沪深300，Baostock 代码为 `sh.000300`
- 无风险收益率：国债年化 3%，日无风险收益率按 `0.03 / 250 = 0.00012`
- 异常值处理：按老师补充说明，使用 `winsorize(return, limits=[0.01, 0.01])` 进行 1%/99% 缩尾
- 显著性阈值：Alpha 的 p 值小于 `0.1`

## 运行方法

在仓库根目录执行：

```bash
pip install -r requirements.txt
python homework2/main.py
```

如需强制重新从 Baostock 拉取数据：

```bash
python homework2/main.py --refresh
```

## 当前运行结果

在 `p < 0.1` 的显著性标准下，只有泸州老窖的 Alpha 显著：

| 股票 | 日 Alpha | 年化 Alpha | Alpha p 值 | Beta |
| --- | ---: | ---: | ---: | ---: |
| 泸州老窖 | 0.001756 | 43.90% | 0.0337 | 1.5704 |

因此回测标的选择泸州老窖。2023-2024 买入并长期持有的回测结果如下：

| 指标 | 泸州老窖 | 沪深300 |
| --- | ---: | ---: |
| 累计收益率 | -43.35% | 1.08% |
| 最大回撤 | -61.62% | -24.80% |
| 卡玛比率 | -0.7035 | 0.0435 |

结论：2020-2022 年 CAPM 拟合得到的显著正 Alpha，并没有在 2023-2024 年长期持有回测中转化为超额收益，说明理论 Alpha 具有明显的不稳定性和时段依赖性。

补充实验继续拉长泸州老窖持有期，结果显示持有到 2025 年底累计收益为 `-47.41%`，持有到最新可得交易日 `2026-05-18` 累计收益为 `-59.29%`。延长时间没有修复历史回撤，反而扩大了相对沪深300的落后幅度。
