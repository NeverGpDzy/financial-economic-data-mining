## 一、作业目的

- 本地数据预处理
- 高阶因子计算
- IC/IR+共线性双质检
- 机器学习非线性赋权
- 日频截面选股
- 样本外回测验证

**核心目标：** 基于沪深300成分股构建中频短线量化模型，掌握日频因子筛选、AI辅助编程、中频交易规则与回测的工业界标准方法；掌握AI代码审核。

## 二、核心研究设计

- **研究标的：** 沪深300指数成分股（共300只，A股流动性最优、数据完整度最高，适配中频1~2日交易）

  - 辅助工具：AI编程助手（TRAE/Codeybuddy）

## 三、因子标准定义（中频短线1~2日持仓核心）

| 因子 | 定义 |
|------|------|
| **Reversal** | -前1日个股收益率（中频核心，超短反转预测收益） |
| **Liquidity** | Amihud非流动性指标（日振幅/日成交额，衡量交易摩擦） |
| **MoneyFlow** | 当日主力大单净额 = buy_amount - sell_amount；5日滚动净流入 = 大单净额.rolling(window=5, min_periods=1).sum()；MoneyFlow = 5日滚动净流入 ÷ 个股自由流通市值 |
| **Value** | PE_TTM倒数（正向化，低估值增强收益稳定性） |

## 四、分模块任务

### 模块1：本地数据加载与预处理（35分）

**任务：** 读取教师预下载本地数据，计算日频收益率、中频因子，完成清洗、去极值、数据集拆分。

**操作步骤：**
1. **数据提取：** 读取本地Parquet格式数据（沪深300成分股日频/5分钟线、财务、daily_basic、指数数据）
2. **指标计算：**
   - 个股日频收益率 = (当日收盘价/前日收盘价)-1
   - 市场日频收益率 = 沪深300指数日收益率
   - 超额收益 = 个股日收益率 - 无风险利率（日0.01%）
   - 合成Reversal/Liquidity/MoneyFlow/Value因子
3. **数据清洗：**
   - 缺失值：市值/因子前值填充，收益率剔除停牌日
   - 异常值：3σ缩尾处理（超出[μ-3σ,μ+3σ]用边界值替换）
4. **数据集拆分：**
   - 训练集：2020-2023
   - 回测集：2024-2025
5. 输出清洗后数据集CSV，配数据说明表

### 模块2：因子质检（IC/IR+共线性检验）（15分）

1. **因子标准化（5分）：** Z-Score标准化 Factor_std = (Factor-μ)/σ
2. **IC/IR计算（6分）：**
   - IC定义：当期因子值与次日收益率的Spearman秩相关系数
   - 计算：按日截面计算，得到日度IC序列，Newey-West调整t检验
   - 判定标准：IC均值>0.02有效，IC均值>0.05优秀；IR=IC均值/IC标准差，|IR|>0.1稳定
   - IC筛选规则：
     - |IC|≥0.02：判定为初步有效，直接进入单因子检验
     - 0.01≤|IC|<0.02：边缘因子，留存进入后续两轮校验
     - |IC|<0.01：全周期无效因子（课程规则：保留全流程测试）
3. **共线性检验（4分）：** VIF方差膨胀因子，VIF>5判定高共线

### 模块3：单因子有效性检验（20分）

- **步骤1：** 单因子横截面回归
  - 回归公式：Return_{i,t+1} = α + β×Factor_{i,t} + ε
  - 因变量：个股次日超额收益
  - 自变量：4个标准化单因子
- **步骤2：** 有效因子判定
  - 因子系数β显著（p<0.05）→ 判定为有效中频因子
  - 判断规则：
    1. 全部4只因子强制完成日截面单因子OLS检验，单因子环节不做任何剔除
    2. OLS仅用于线性有效性量化评估：p<0.05=线性有效；p≥0.05=线性维度失效、列入待定池
    3. 所有待定因子全部顺延进入LGBM非线性二次筛选

### 模块4：多因子机器学习赋权（LGBM非线性）（15分）

1. **建模数据准备（4分）：** 特征=所有因子标准化值，标签=个股次日超额收益，仅用2020-2023训练集
2. **LGBM机器学习建模（6分）：** LightGBM回归模型，输出特征重要性、模型拟合结果
3. **模型保存（5分）：** 保存训练完成的LGBM预测模型，用于后续样本外打分选股

### 模块5：日频截面选股+1~2日持仓样本外回测（15分）

**第一部分：综合得分定义与日频截面选股（6分）**
- 综合得分 = 训练好的LGBM模型预测的个股次日超额收益
- 每日截面打分：按综合得分从高到低排序
- 选股规则：选Top5，等权持仓
- 交易规则：
  1. 调仓：每日调仓，平均持仓1~2日
  2. 仓位：5只等权，单票≤20%
  3. 流程：卖出旧持仓→买入新持仓，扣双边交易成本

**第二部分：样本外回测（9分）**
- 回测参数：初始资金100万元，交易成本单边0.1%，回测区间2024-2025
- 必算指标：累计收益率、年化收益率、夏普比率、最大回撤、日胜率、超额收益（相对沪深300）
- 输出：策略净值VS沪深300对比图、回测指标表格
