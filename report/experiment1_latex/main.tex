\section{实验目标}

本实验的核心任务是将非结构化金融新闻文本转化为结构化的周度市场情绪指标，完成数据工程核心环节。具体目标如下：

\begin{enumerate}
    \item 对给定金融新闻文本完成轻量化预处理，基于 BERT（Transformer）实现中文金融文本三分类情感量化标注；
    \item 按交易日维度聚合生成 WeekPositive、WeekNeutral、WeekNegative 标准化周度情绪指标；
    \item 输出结构化周度数据，为实验二羊群效应建模提供稳定输入。
\end{enumerate}

全流程入口为：
\begin{CodeBlock}
python -m experiment1.main
\end{CodeBlock}

\section{数据清洗与情绪标注}

程序先将新闻发布时间转为标准日期，保留 2014-10-01 至 2015-10-31 区间内正文非空的样本，再按正文去重，并用沪深300交易日历剔除非交易日新闻。情绪标注使用 \path{yiyanghkust/finbert-tone-chinese} 完成正面、中性、负面三分类；当模型文件不可用时，代码提供金融情绪词典回退路径以保证可运行性。

周度情绪占比定义为：
\begin{equation}
P_t=\frac{WeekPositive_t}{WeekPositive_t+WeekNegative_t}.
\end{equation}

\section{周度情绪指标}

按每周统计 WeekPositive（正面文本总数）、WeekNeutral（中性文本总数）、WeekNegative（负面文本总数），并计算 P\_t 情绪占比。程序将结果写入 \path{weekly_sentiment.csv} 和 SQLite 数据库 \path{experiment1.db}。

\section{情绪指标数据质量分析}

\begin{itemize}
    \item 周度情绪表共 51 行，覆盖 2014-10 至 2015-10 全样本区间；
    \item 所有周的 WeekPositive + WeekNegative 均大于 0，P\_t 计算有效；
    \item P\_t 均值约 0.82，说明样本期间市场整体偏乐观；
    \item 无缺失值、无异常跳变，数据质量满足后续羊群效应构建要求。
\end{itemize}

\section{实验总结}

本实验完成了从非结构化金融新闻文本到结构化周度情绪指标的全流程：数据清洗将 60000 条原始新闻筛选为 30623 条交易日新闻；BERT 模型完成三分类情感标注；按 5 个交易日聚合生成 51 行周度情绪表。输出的 weekly\_sentiment.csv 将作为实验二构建羊群效应指数的输入。
