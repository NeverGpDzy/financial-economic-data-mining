**《金融与经济数据挖掘》作业3：二因子模型**

学习课件、教材及参考资料，上网调研，完成以下工作：

**一、实验目的**

- 掌握单因子 CAPM 模型与二因子模型的构建、回归与对比方法
- 理解估值因子（PETTM）对股票收益的解释作用
- 学会使用 Python 进行金融数据获取、异常值处理、回归分析
- 基于二因子模型的估值逻辑，使用PEG 策略进行样本外回测，验证模型实践效果

**二、实验原理**

1. 单因子 CAPM 模型
2. 二因子模型（标准规范）
3. 市场因子：(Rm - Rf) 市场超额收益
4. 估值因子：PETTM（滚动市盈率，衡量股票估值水平）
5. PEG 策略：基于估值与成长性的择时策略

备注：
- Ri：代表个股（计算中按每日收盘价格变化百分比算）
- Rf：无风险资产，通常使用银行存款或国债的年化收益率
- Rm：市场指数收益率，即大盘收益率（计算中按每日收盘价格变化百分比算）

**三、实验数据**

1. 数据来源：baostock 免费数据接口
2. 股票池：实验指定个股
3. 时间区间：样本内 + 样本外
4. 无风险利率：一年期定期存款利率（Rf = 1.5%）
5. 数据字段：收盘价、PETTM、指数收益率

**四、实验步骤：**

**1. 数据获取与方程拟合**

（1）使用baostock数据接口，通过Python编程，获取2018-2022年（共5年）6只股票（贵州茅台、中国石油、五粮液、泸州老窖、招商银行、美的集团）的日度收盘价数据，计算日价格变动收益率；获取上证指数日度收盘价数据，计算其日收益率作为市场因子（MKT）；同时获取无风险利率（建议使用一年期国债收益率，按日插值处理），计算个股超额收益率（Ri - Rf）和市场超额收益率（Rm - Rf），完成CAPM模型拟合。

（2）获取上述6只股票的日频PETTM数据，对PETTM进行最大最小归一化处理（归一化公式：归一化后值 = (原始值 - 最小值) / (最大值 - 最小值)），消除量纲影响。

（3）修正说明：PETTM属于估值因子。将CAPM模型扩展为二因子模型，新增PETTM（估值因子）作为第二个解释变量，构建方程：个股超额收益率（Ri - Rf）= α + β1 × 市场超额收益率（Rm - Rf）+ β2 × 归一化PETTM + ε，将个股超额收益拟合为市场超额收益和PETTM的线性函数。

**2. 数据分析**

对二因子模型拟合结果进行详细解释：

（1）各股票在PETTM（估值因子）上的因子暴露（β2系数）含义及大小分析（正/负暴露代表的意义、暴露程度差异原因）；

（2）对比CAPM模型与二因子模型的α（阿尔法）系数，分析加入PETTM因子后，数据异象α是否减少及原因；

（3）结合6只股票所属行业（白酒：茅台、五粮液、泸州老窖；能源：中国石油；金融：招商银行；家电：美的集团），分析不同行业股票的拟合结果差异及背后逻辑。

**3. 回测**

使用二因子模型结合PEG策略进行投资回测，采用2023-2025年（共3年）的日度数据，分析模型实际投资效果，具体回测策略如下：

1. 计算PEG指标：PEG = 归一化后的PETTM / 五年利润平均增长率（明确时间范围：2018-2022年，利润增长率采用算术平均法计算，若出现负增长率，需标注并说明处理方式）；
2. 交易规则：
   - ① 若PEG < 0.8，全仓买入对应股票（若有多只股票同时满足，选择α系数最优的1只；若已满仓，持仓不动）；
   - ② 若PEG > 1.5，全仓卖出对应股票（若已空仓，持仓不动）；
   - ③ 若0.8 ≤ PEG ≤ 1.5，保持现有持仓不变；
3. 初始资金：100万元现金，不考虑交易杠杆，计算回测期间（2023-2025年）的累计收益率、年化收益率、最大回撤、卡玛比率；使用Python绘制累计收益曲线（需包含个股累计收益与上证指数累计收益对比）。
4. 补充要求：回测需考虑交易成本（手续费按0.03%/笔、滑点按0.1%/笔计算），标注交易次数、持仓周期等关键信息。

**五、参考资料**

（1）PETTM（动态市盈率）：指过去12个月（滚动12个月）的公司盈利与公司当前市值的比值，用于衡量公司定价是否被高估/低估。例如：公司过去12个月盈利1亿元，总市值20亿元，则PETTM=20。与静态PE相比，PETTM更贴合实时市场情况，避免了季节性盈利波动的影响。

（2）PEG指标：由彼得·林奇提出，用于衡量股票估值与成长性的匹配度，计算公式为：PEG = PETTM / 利润平均增长率（本次统一采用2018-2022年算术平均增长率）。

（3）PEG投资逻辑：彼得·林奇认为，PEG < 0.8时，股票价格被低估，具有投资价值；PEG > 1.5时，股票价格被高估，建议卖出；0.8 ≤ PEG ≤ 1.5时，估值与成长性匹配，可持有。PEG方法暗含市场情绪影响，能反映市场对个股成长性的预期，可作为估值因子补充到二因子模型中，提升模型解释力。

（4）补充参考：
- ① 无风险利率获取：可通过baostock或Wind获取一年期国债收益率，按日插值处理为日度数据；
- ② 最大最小归一化：用于消除不同指标的量纲差异，确保PETTM因子与市场因子可共同参与模型拟合；
- ③ 因子暴露含义：β2为正，说明个股收益与PETTM正相关（PETTM越高，个股收益越高）；β2为负，说明个股收益与PETTM负相关（PETTM越高，个股收益越低）。

**六、注意事项**

2. 模型拟合需使用statsmodels库，输出回归结果摘要，重点关注α、β系数的显著性（P值）；
